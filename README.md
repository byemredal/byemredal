### 🧠 Currently building: Persona

Most AI tools are good at talking and bad at remembering. **Persona** is my attempt at the opposite.

You tell it about your life, the people, places, plans and things that happened, and it keeps them as **structured, historical memory**. Later it can answer questions about them and show you **where each answer came from**. It doesn't act on your behalf. It just remembers, carefully.

A few principles I'm building it around:

- **The LLM is never the source of truth.** The model proposes structured data, and domain rules validate it before anything is stored.
- **History is kept, not overwritten.** "Current state" is a query over what happened, not a replaced record.
- **Privacy is a design constraint.** No personal data in logs, clear deletion and correction, and every decision written down as an ADR.

Under the hood: .NET · PostgreSQL + pgvector · Python / FastAPI · RabbitMQ · Expo / React Native

Persona is still in development. More at **[qaxora.com](https://qaxora.com)**.
